# Keyboard shortcuts

Mado's default shortcuts on macOS, generated from the settings registry by `cargo test -p mado-settings` (run with `MADO_UPDATE_DOCS=1` to rewrite this file). They follow Chrome's macOS shortcuts; commands Chrome has no shortcut for have none. Every one can be changed in Settings › Keyboard shortcuts. Reserved shortcuts reach the menu before the page.
