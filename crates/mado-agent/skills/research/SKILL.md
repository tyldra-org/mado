# Research

1. Search for the question with the address bar's search engine, or open the sites the person named.
2. Open two to four sources that disagree or add something; prefer primary sources over summaries.
3. Read each with the text tool. Note what each says and when it was written.
4. Answer in a few sentences. Say where sources disagree and which one you trust more, and why.
5. End with a Sources list of the pages you used.
