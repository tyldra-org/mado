# Compare prices

1. Find the exact product: model number, size and colour. If the request is vague, ask.
2. Check the shops the person named, or three well-known shops that sell it.
3. For each, note the price, shipping to the person's country, the total, and whether it is in stock.
4. Do not add anything to a cart or sign in.
5. Answer with a short table, the cheapest total first, then the Sources list.
